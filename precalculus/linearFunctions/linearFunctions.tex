\section{Definition of Linear Functions}

A linear function is a function of the form $f(x) = ax + b$, where $a$ and $b$ are constants. 
If $a = 0$, the function is called a constant function. 
If $a \neq 0$, the function is called a non-constant linear function, or just a linear function.
