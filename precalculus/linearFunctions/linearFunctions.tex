\section{Definition of Linear Functions}
A \textbf{linear} function is a function of the form $f(x) = ax + b$, where $a$ and $b$ are constants. 
If $a = 0$, the function is called a \textbf{constant} function. 
If $a \neq 0$, the function is called a non-constant linear function, or just a linear function. 

\begin{example}(Example 1)
Identify which of the following are linear functions:
\begin{enumerate}
\item $f(x) = 2x + 3$
\item $g(x) = x^2 + 1$
\item $h(x) = -5x$
\end{enumerate}
\begin{solution}
\begin{enumerate}
\item $f(x) = 2x + 3$ is a linear function since it is of the form $ax + b$ with $a = 2$ and $b = 3$.
\item $g(x) = x^2 + 1$ is not a linear function since it contains a term with $x^2$, which is not of the form $ax + b$.
\item $h(x) = -5x$ is a linear function since it is of the form $ax + b$ with $a = -5$ and $b = 0$.
\end{enumerate}
\end{solution}
\end{example}

\begin{example}(Example 2)
Classify the function as constant, linear or neither:
\begin{enumerate}
\item $f(x) = 4$ 
\item $g(x) = -3x + 2$ 
\item $h(x) = x^2 - 1$    
\end{enumerate} 
\begin{solution}
\begin{enumerate}
\item $f(x) = 4$ is a constant function since it is of the form $f(x) = b$ with $b = 4$.
\item $g(x) = -3x + 2$ is a linear function since it is of the form $f(x) = ax + b$ with $a = -3$ and $b = 2$.
\item $h(x) = x^2 - 1$ is neither a constant nor a linear function since it contains a term with $x^2$, which is not of the form $ax + b$ or $b$.    
\end{enumerate}
\end{solution}     
\end{example}

\section{Graphs of Linear Functions}

The graph of a linear function in the $(x,y)$-plane is a straight line.
To create the graph of a linear function, we can find two points on the line and then draw the unique line through those points.
\begin{example}(Example 3)
Graph the linear function $f(x) = 2x + 1$.\\
To graph the function, we can find two points on the line.
When $x = 0$, $f(0) = 2(0) + 1 = 1$, so the point $(0,1)$ is on the line.
When $x = 1$, $f(1) = 2(1) + 1 = 3$, so the point $(1,3)$ is on the line.
Now we can draw the line through the points $(0,1)$ and $(1,3)$ to graph the function.

\section{Slope and Rate of Change}
The slope of a line is a number which tells us important information about the behavior of the line.
A line passing through the two points $(x_1, y_1)$ and $(x_2, y_2)$ has \textbf{slope}
\[
m = \frac{\text{rise}}{{\text{run}}} = \frac{\delta y}{delta x} = \frac{y_2 - y_1}{x_2 - x_1}
\]
provided that $x_2 \neq x_1$.
\begin{example}[Example 4]
Find the slope of the line that goes through the points $(-2, 1)$ and $(3, -4)$.\\
First, we label the points: $(x_1, y_1) = (-2, 1)$ and $(x_2, y_2) = (3, -4)$
The slope of the line is then given by
\[
m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{-4-1}{3-(-2)}= -1
\]
Note that the labeling of the points was arbitrary. Had we chosen:
$(x_1, y_1) = (3, -4)$ and $(x_2, y_2) = (-2, 1)$, 
we would have obtained
\[
m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{1-(-4)}{-2-3}= -1
\]
Thus, the slope is not affected by the labelling.
\end{example}

\begin{remark}
Since $b-a = -(a-b)$, the fractions: $\dfrac{y_2 - y_1}{x_2 - x_1}$ and $\dfrac{y_1 - y_2}{x_1 - x_2}$
are equal.
Hence, the result of the slope calculation does not depend on the choice of labels for the given points.
\end{remark}

\begin{problem}(Problem 4a)
Find the slope of the line that goes through the points $(5, 2)$ and $(1, 4)$.\\
The slope is $m = \answer{-1/2}$
\end{problem}

\begin{problem}(Problem 4b)
Find the slope of the line that goes through the points $(1, -3)$ and $(4, 7)$.\\
The slope is $m = \answer{10/3}$
\end{problem}

\begin{problem}(Problem 4c)
Find the slope of the line that goes through the points $(-4, -1)$ and $(6, 3)$.\\
The slope is $m = \answer{2/5}$
\end{problem}

If a line has a positive slope, then the associated linear function is increasing, 
meaning that the graph will rise as we move from left to right. If the slope is negative, the function is decreasing and the 
graph falls from left to right, and if the slope is zero, then the function is constant and the line is horizontal.
The slope of a vertical line is undefined, as the slope formula would yield a division by zero.

\begin{example}[Example 5]
Find the slope of the graph of the linear function $f(x) = 3x + 5$. \\
We first find two points on the line by selecting two values for $x$ and computing the corresponding values 
of $y = f(x) = 3x + 5$.
\end{example}

\begin{problem}
Find the slope of the graph of the linear function $g(x) = -2x + 4$.\\
The slope is $m = \answer{-2}$
\end{problem}

\begin{problem}
Find the slope of the graph of the linear function $h(x) = 7 - 4x$.\\
The slope is $m = \answer{-4}$
\end{problem}

The slope, $m$, of the line $y = mx + b$ tells us the rate of change of the dependent variable, $y$, with respect to the independent 
variable, $x$. In other words, a change of $\Delta x$ in the variable $x$ will result in a change of $m \Delta x$ in the variable $y$.
